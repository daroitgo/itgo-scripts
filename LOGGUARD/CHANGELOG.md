# Changelog

## 0.1.0

- Added the initial LOGGUARD foundation as a private, user-local module.

- Added read-only `status`, `scan`, `version`, and `help` commands.
- Deliberately deferred rotation, archival, compression, retention, COPYTRUNCATE execution, and all system-level integration.

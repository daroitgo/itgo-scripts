# P1CERT certificate payload

This directory reserves the versioned official production P1 certificate payload for future `VERIFY` and `UPDATE` functionality.

When supplied, its release filename is `p1-production-certs.zip`. No payload is included in P1CERT 0.1.0 and this module currently makes no certificate changes.

The ZIP is versioned together with its P1CERT release. Changing its contents requires a new P1CERT version and tag; it must never be replaced under an existing tag.
